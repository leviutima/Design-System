# @leviutima/ds

A quiet, neutral design system for React 19 and Tailwind CSS 4.

## Install

```sh
npm i @leviutima/ds
```

Import the styles after Tailwind in your main CSS file:

```css
@import 'tailwindcss';
@import '@leviutima/ds/styles.css';
```

Then import the components you need:

```tsx
import { Button, Field, Input } from '@leviutima/ds'

export function SignInForm() {
  return (
    <form className="flex flex-col gap-4">
      <Field label="Email" required>
        <Input type="email" />
      </Field>
      <Button type="submit">Sign in</Button>
    </form>
  )
}
```

## Principles

- **Soft neutrals.** Warm graphite on white, or light gray on near black, with no accent color.
- **Small radius, light borders.** Controls have a 4px radius and no shadows.
- **Gentle feedback.** Hover and press only shift a surface slightly.
- **Errors in words.** Errors use a darker border, an icon and a message, so they never depend on color.

## Themes

The system theme applies by default. Set `data-theme="light"` or `data-theme="dark"` on any element to force a theme inside it.

## Customizing

Every component accepts `className`, and a later Tailwind class replaces the one it conflicts with. The system font is used by default. To change it, override `--font-sans` and `--font-mono` in your own `@theme`.
